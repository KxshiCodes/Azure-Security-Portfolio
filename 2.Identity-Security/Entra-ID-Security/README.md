# Microsoft Entra ID Security

Practical identity management and security exercises using Microsoft Entra ID, focused on user administration, access control, and identity protection.

## User & Group Management

Worked through a simulated organisational scenario using a delegated User Administrator role.

The exercise covered:

- Creating and managing user accounts
- Creating security groups and managing membership
- Assigning and removing group ownership
- Reviewing directory role permissions
- Resetting user credentials
- Reviewing sign-in activity
- Disabling suspicious or compromised accounts
- Restoring deleted users
- Cleaning up test identities and groups

## Identity Security Concepts

Explored key Microsoft Entra ID security capabilities and their role in protecting organisational identities.

| Security Area | Concepts |
|---|---|
| Zero Trust | MFA, Conditional Access, continuous verification |
| Identity Protection | Risky users, risky sign-ins, risk remediation |
| Identity Governance | PIM, access reviews, privileged access |

## Outcome

Developed practical experience with identity lifecycle management, delegated administration, group-based access, and directory permissions.

The exercises also provided an understanding of how identity protection and governance controls help reduce unauthorised access and protect privileged accounts.
